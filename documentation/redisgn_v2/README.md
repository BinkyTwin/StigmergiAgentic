# Redesign V2 Sprint Artifact Notes

This folder is mandatory for all future sprint deliveries.

## Rule

At the end of each sprint, the active agent must create or update one sprint file that describes the **current functioning of the artifact**.

- Location: `documentation/redisgn_v2/`
- File naming: `sprint_XX_artifact.md` (example: `sprint_01_artifact.md`)
- Language: English (technical and reusable)

## Required sections in each sprint file

1. Sprint scope
2. Current artifact behavior
3. Public interfaces and contracts
4. Guardrails and constraints
5. Known limits / not implemented yet
6. Validation evidence (commands + result summary)

## Process integration

For each sprint closure, update all:
- `documentation/redisgn_v2/sprint_XX_artifact.md`
- `documentation/construction_log.md`
- `AGENTS.md`
- `CLAUDE.md`
