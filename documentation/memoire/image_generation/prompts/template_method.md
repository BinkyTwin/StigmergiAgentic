# Contexte à visualiser

Décris ici la section de méthode, l'architecture ou le mécanisme que la figure
doit représenter. Écris comme si tu donnais à un designer scientifique les
éléments qui doivent absolument apparaître dans l'image.

## Éléments obligatoires

- Composant principal 1.
- Composant principal 2.
- Flux de données ou de décision.
- Point de validation ou de contrôle.

## Style souhaité

Diagramme académique propre, fond blanc, palette sobre mais contrastée,
typographie lisible, flèches nettes, peu de texte, pas de titre intégré dans
l'image.
