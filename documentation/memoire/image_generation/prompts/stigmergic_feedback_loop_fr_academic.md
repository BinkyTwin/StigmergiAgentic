# Passage à illustrer

La stigmergie est un mécanisme de coordination indirecte par lequel les
acteurs se coordonnent en modifiant un environnement commun. Le terme fut
introduit par Pierre-Paul Grassé à partir de l'observation des termites :
des individus semblent travailler localement et indépendamment, mais leurs
actions produisent collectivement une structure cohérente. Une action laisse
une trace dans l'environnement ; cette trace devient un stimulus pour une
action suivante ; l'environnement est alors modifié, créant une nouvelle
configuration qui oriente de nouvelles réponses. Dans les formalisations
algorithmiques, ces traces peuvent être déposées, renforcées lorsqu'elles sont
utiles, ou s'évaporer lorsqu'elles deviennent moins pertinentes.

## Figure à générer

Créer un schéma académique en français uniquement représentant une boucle de
rétroaction stigmergique. La figure doit être sobre, sérieuse, utilisable dans
un mémoire ou un article scientifique.

## Structure obligatoire

Utiliser une boucle circulaire en cinq étapes, avec des flèches nettes et un
centre conceptuel :

1. Configuration environnementale A
2. Agent local observe une trace
3. Action située
4. Modification de l'environnement
5. Nouvelle configuration A'

Au centre, indiquer le principe : coordination indirecte par traces.

## Contenu visuel obligatoire

- Montrer l'environnement comme un support matériel ou numérique commun.
- Montrer une trace ou un stimulus visible dans cet environnement.
- Montrer qu'un agent local lit cette trace puis agit.
- Montrer que l'action modifie l'environnement au lieu d'envoyer un message
  direct à un autre agent.
- Montrer la boucle de feedback : configuration -> trace/stimulus -> action ->
  modification -> nouvelle configuration.
- Ajouter discrètement les mécanismes algorithmiques : dépôt, renforcement,
  évaporation.

## Style

- Langue française uniquement.
- Aucun libellé anglais.
- Pas de titre bilingue.
- Pas de caption intégrée dans l'image.
- Pas de source ou référence bibliographique dans l'image.
- Pas de paragraphes dans l'image.
- Diagramme académique propre, fond blanc.
- Style article scientifique : lignes fines, icônes simples, peu de décor.
- Palette sobre : noir/gris, bleu profond, vert discret, accent orange limité.
- Typographie lisible et labels courts.
- Éviter les mascottes, cartoons ou insectes trop réalistes ; si un termite est
  représenté, utiliser une icône minimale et sérieuse.

## Caption / intention visuelle

Boucle de rétroaction stigmergique : une action modifie l'environnement, ce qui
déclenche l'action suivante. Ne pas écrire cette phrase dans l'image.
